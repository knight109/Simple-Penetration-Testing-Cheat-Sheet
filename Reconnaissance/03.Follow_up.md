# Follow Up
After reconnaissance, investigate interesting findings discovered on the target.
> Only perform these checks against systems you own or have explicit permission to test.
---

## 1. Check Interesting Paths
Check commonly exposed files and directories.
```bash
curl -i http://<TARGET>:<PORT>/robots.txt
curl -i http://<TARGET>:<PORT>/internal-notes/
curl -i http://<TARGET>:<PORT>/admin/
curl -i http://<TARGET>:<PORT>/.env
```
Check for backup or configuration files:
```bash
curl -i http://<TARGET>:<PORT>/config.php.bak
curl -i http://<TARGET>:<PORT>/backup/config.php
```
---

## 2. Check API Documentation
Look for API documentation or OpenAPI specifications.
```bash
curl -s http://<TARGET>:<PORT>/api/swagger.json | jq .
curl -s http://<TARGET>:<PORT>/swagger.json | jq .
curl -s http://<TARGET>:<PORT>/openapi.json | jq .
```
---

## 3. Find Hidden Directories
Use FFUF to discover additional web paths.
```bash
ffuf -u http://<TARGET>:<PORT>/FUZZ \
-w /usr/share/wordlists/dirb/common.txt \
-fs <SIZE_404>
```
---

## 4. Check Backup Files
Check whether a backup file exists:
```bash
curl -I http://<TARGET>:<PORT>/backup.zip
```
Download it if it is publicly accessible:
```bash
wget http://<TARGET>:<PORT>/backup.zip -O backup.zip
```
List its contents:
```bash
unzip -l backup.zip
```
Extract the files:
```bash
unzip backup.zip -d backup/
```
---

## 5. Search Extracted Files
Search for potentially interesting information.
```bash
grep -RniE "password|passwd|secret|token|db_|database|swagger|api|\.env" backup/
```
Look for:
* Credentials
* API keys
* Tokens
* Database configuration
* Internal endpoints
* API documentation
* Environment variables
* Backup configuration
---

## 6. Document the Finding
Record anything interesting for further investigation.
```text
Finding      : /backup/
Type         : Backup
Evidence     : backup.zip
Interesting  : Database configuration found
Next Step    : Review configuration and identify exposed services
```
