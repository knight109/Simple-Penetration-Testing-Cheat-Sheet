# Active Reconnaissance
Active reconnaissance is the process of gathering information by directly interacting with the target system.
> Only perform active reconnaissance against systems you own or have explicit permission to test.
---

## 1. Check Host Availability
Check whether the target is reachable.
```bash
ping -c 4 <TARGET>
```
---

## 2. Identify IP Address
Resolve the target domain to an IP address.
```bash
host <TARGET>
```
or:
```bash
dig <TARGET>
```
---

## 3. Nmap Scanning
Use Nmap to identify open ports, services, versions, OS, and common vulnerabilities.
### Network Discovery
```bash
nmap -sn <NETWORK>/<CIDR>
```
### Basic Scan
```bash
nmap <TARGET>
```
### All TCP Ports
```bash
nmap -p- <TARGET>
```
### Service & Version Detection
```bash
nmap -sV <TARGET>
```
### OS Detection
```bash
nmap -O <TARGET>
```
### Default Scripts
```bash
nmap -sC <TARGET>
```
### Recommended Scan
```bash
sudo nmap -sC -sV -O <TARGET>
```
```bash
sudo nmap -sC -sV -O -p- <TARGET>
```
Example result:
```text
22/tcp   open  ssh     OpenSSH
80/tcp   open  http    Apache
3306/tcp open  mysql   MySQL
```
---

## 4. Web Enumeration
If HTTP/HTTPS is available, inspect the web service.
```bash
curl -I http://<TARGET>
```
Check the response headers:
```bash
curl -i http://<TARGET>
```
Look for:
* Server
* Technologies
* Cookies
* Redirects
* Security headers
---

## 5. Web Directory Enumeration
Look for accessible directories and files on a web server.
### Gobuster
```bash
gobuster dir -u http://<TARGET>:<PORT> -w <WORDLIST>
```
### FFUF
```bash
ffuf -u http://<TARGET>:<PORT>/FUZZ -w <WORDLIST>
```
### Dirsearch
```bash
dirsearch -u http://<TARGET>:<PORT>
```
Using a specific wordlist:
```bash
dirsearch -u http://<TARGET>:<PORT> -w <WORDLIST>
```
### Dirb
```bash
dirb http://<TARGET>:<PORT>
```
Using a specific wordlist:
```bash
dirb http://<TARGET>:<PORT> <WORDLIST>
```
### Feroxbuster
```bash
feroxbuster -u http://<TARGET>:<PORT>
```
Using a specific wordlist:
```bash
feroxbuster -u http://<TARGET>:<PORT> -w <WORDLIST>
```
### Common Targets
```text
/admin
/login
/uploads
/backup
/config
/api
/dev
/test
```
Common wordlist locations:
```text
/usr/share/wordlists/
/usr/share/seclists/
```
Useful things to check:
* Hidden directories
* Backup files
* Configuration files
* Login pages
* Upload directories
* API endpoints
* Development or testing directories
---

## 6. Virtual Host Enumeration
Look for virtual hosts hosted on the same server.
Using FFUF:
```bash
ffuf -u http://<TARGET>:<PORT> \
-H "Host: FUZZ.<TARGET>" \
-w <WORDLIST>
```
Possible results:
```text
dev.<TARGET>
test.<TARGET>
admin.<TARGET>
```
---

## 7. DNS Enumeration
Query DNS records directly from the target's DNS infrastructure.
```bash
dig <TARGET> ANY
```
Query specific records:
```bash
dig <TARGET> A
dig <TARGET> MX
dig <TARGET> NS
dig <TARGET> TXT
```
---

## 8. Service-Specific Enumeration
Once open ports are identified, enumerate the corresponding services.
### SSH
```bash
nmap -p <PORT> --script ssh-* <TARGET>
```
### HTTP
```bash
nmap -p <PORT> --script http-* <TARGET>
```
### SMB
```bash
nmap -p <PORT> --script smb-* <TARGET>
```
### FTP
```bash
nmap -p <PORT> --script ftp-* <TARGET>
```
---

## 9. Record the Results
Organize the discovered information.
```text
Target       : <TARGET>
IP           : <TARGET-IP>
Open Ports:
<PORT>/tcp   : <SERVICE>
<PORT>/tcp   : <SERVICE>
<PORT>/tcp   : <SERVICE>
Web Server   : <WEB-SERVER>
OS           : <OS>
Directories:
 /<DIRECTORY>
 /<DIRECTORY>
 /<DIRECTORY>
```
Use the results from active reconnaissance to determine which services and applications should be investigated during the next phase.
