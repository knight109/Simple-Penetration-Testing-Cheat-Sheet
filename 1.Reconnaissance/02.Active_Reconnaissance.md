# Active Reconnaissance
Active reconnaissance is the process of gathering information by directly interacting with the target system.

## 1. Check Host Availability
Check whether the target is reachable.
```bash
ping -c 4 <TARGET>
```

## 2. Identify IP Address
Resolve the target domain to an IP address.
```bash
host <TARGET>
```
or:
```bash
dig <TARGET>
```

## 3. Initial Nmap Scan
Identify accessible hosts and open ports.
### Network Discovery
```bash
nmap -sn <NETWORK>/<CIDR>
```
### Basic Scan
```bash
nmap <TARGET>
```

## 4. Technology Fingerprinting
Identify the technologies used by the target.
**Wappalyzer** — Browser extension for identifying web technologies.

**WhatWeb:**
```bash
whatweb <TARGET>
```
**HTTP Headers:**
```bash
curl -I http://<TARGET>:<PORT>
```
Look for:
* Web server
* Programming language
* Framework
* CMS
* JavaScript libraries
* Technology versions

## 5. Initial Web Discovery
Identify the main web application and its accessible functionality.
Look for:
```text
/login
/admin
/upload
/api
/register
```
Also identify:
* Login pages
* Upload functionality
* API presence
* Interesting pages
* Application type
## 6. Record the Results

```text
Target       : <TARGET>
IP           : <TARGET-IP>
Open Ports   :
Technologies :
Web Server   :
Application  :
Interesting  :
```
Use the results from active reconnaissance to determine what should be investigated during the **Scanning & Enumeration** phase.
