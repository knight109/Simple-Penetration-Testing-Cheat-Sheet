# Rules of Engagement
Rules of Engagement (RoE) define the rules, limitations, and procedures for conducting a penetration test.

## Testing Schedule
```text
Start:
End:
Allowed Hours:
```

## Allowed Activities
Define the techniques that are permitted during testing.
```text
Allowed:
- Port scanning
- Vulnerability scanning
- Web enumeration
- Exploitation
```

## Restricted Activities
Define activities that require approval or are not allowed.
```text
Restricted:
- Denial-of-Service testing
- Destructive testing
- Data deletion
- Production data modification
```

## Emergency Procedure
Define what to do if testing causes unexpected impact.
```text
Stop Condition:
Emergency Contact:
Escalation Procedure:
```

## Communication
```text
Technical Contact:
Emergency Contact:
Pentest Lead:
```
* Report critical findings immediately.
* Stop testing if the target becomes unstable.
* Follow the agreed escalation procedure.
