# Authorization
Authorization defines the legal permission to perform a penetration test against the target.
> Never perform penetration testing against systems without explicit authorization.

## Required Authorization
Before testing, confirm that the following are available when applicable:
* **Authorization Letter** — Written permission from the system owner.
* **Non-Disclosure Agreement (NDA)** — Defines how confidential information must be handled.
* **Rules of Engagement (RoE)** — Defines how and when testing may be performed.
* **Statement of Work (SoW)** — Defines the agreed testing services and deliverables.

## Verify Before Testing
Confirm:
* [ ] Authorization has been obtained
* [ ] Target owner is identified
* [ ] Testing period is approved
* [ ] Testing scope is defined
* [ ] Required agreements are signed
* [ ] Testing restrictions are understood
