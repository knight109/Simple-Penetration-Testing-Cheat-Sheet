# Target Information
Understand the target system, its purpose, and its environment before testing.

## Basic Information
```text
Target:
Organization:
Application:
Environment:
Purpose:
```

## Understand the Target
Identify:
* What does the system do?
* Who uses it?
* What services does it provide?
* What type of data does it handle?
* Is it a production, staging, or development environment?
* What technologies are known to be used?

## Target Details
Record any information provided by the system owner:
```text
Domain:
IP Address:
Application:
Operating System:
Technology:
Authentication:
```

## Important Notes
Record information that may affect the testing approach:
```text
Known Issues:
Previous Findings:
Known Vulnerabilities:
Special Requirements:
```
