# Network Information
Identify the network configuration of the testing environment before starting the assessment.

## Identify Your IP Address
```bash
ip addr
hostname -I
```
## Identify Network Interface
```bash
ip link
```
## Identify Default Gateway
```bash
ip route
```
## Identify DNS Servers
```bash
resolvectl status
```
## Check Connectivity
```bash
ping -c 4 <TARGET>
```
## Check Target Port
```bash
nc -vz <TARGET-IP> <PORT>
```
## Record Network Information
```text
Tester IP:
Network:
Gateway:
DNS:
VPN:

```
