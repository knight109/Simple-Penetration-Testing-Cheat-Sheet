# Preparation Checklist
## Authorization
* [ ] Authorization obtained
* [ ] NDA completed
* [ ] RoE agreed
## Scope & Objectives
* [ ] In-scope targets identified
* [ ] Out-of-scope targets identified
* [ ] Pentest objectives defined
* [ ] Testing period confirmed
## Target Information
* [ ] Target purpose understood
* [ ] Target environment identified
* [ ] Known technologies documented
* [ ] Previous findings reviewed
## Network Information
* [ ] Tester IP identified
* [ ] Network identified
* [ ] Gateway identified
* [ ] DNS identified
* [ ] VPN connection verified, if required
* [ ] Target connectivity verified
## Ready for Testing
* [ ] Required tools available
* [ ] Workspace prepared
* [ ] Testing restrictions understood
* [ ] Emergency contact available
